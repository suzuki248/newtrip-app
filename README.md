# アプリケーション概要

## プロジェクト名
Travel App (Trip App)

## 開発の背景と目的
旅行の計画を立てる際、「どこに行くか」「どのルートで回るか」「タイムスケジュールはどうするか」を自分で調べ、整理し、組み立てるのには非常に多くの時間と労力がかかります。
本アプリケーションは、このような「旅行プラン作成の煩わしさ」という課題を解決するために開発されました。AIを活用することで、ユーザーが簡単な希望を入力するだけで最適な旅程を自動生成し、誰もが手軽でスムーズに旅行の計画を立てられる体験を提供します。

## 概要
本アプリケーションは、AI（Google Gemini API）を活用してユーザーの希望に合わせた旅行プランを自動生成し、地図上でルートや旅程を視覚的に管理できる旅行プラン作成アプリです。

## 主な機能
1. **AIトラベルウィザード機能**
   - 目的（アクティビティ）、目的地、詳細条件（日程、人数など）をステップ形式で入力し、AIが最適な旅行プランを提案します。
2. **インタラクティブな旅程・マップ表示**
   - 生成された旅行プラン（旅程）をGoogle MapsやLeafletを活用した地図上で視覚的に確認・管理できます。
3. **プラン保存・管理機能**
   - 作成したお気に入りの旅行プランを保存し、後からマイページ（My Plans）で閲覧・管理することが可能です。

## 技術スタック
### フロントエンド
- **コアフレームワーク**: React (v19) / Create React App
- **ルーティング**: React Router
- **スタイリング・UI**: Bootstrap, Animate.css, Font Awesome, Ionicons
- **データ可視化**: Recharts

### API通信・データ処理
- **API連携**: Axios
- **データ管理**: ブラウザの標準機能（LocalStorage等）によるデータ保存

### 外部連携API
- **生成AI**: Google Gemini API (`@google/genai`)
- **地図サービス**: Google Maps API (`@googlemaps/js-api-loader`), Leaflet / React-Leaflet

## 特徴
最新のReactエコシステムを採用し、モダンでレスポンシブなSPA（シングルページアプリケーション）として構築されています。ユーザーは直感的なインターフェースを通じて、AIによるスマートかつ視覚的な旅行計画体験を得ることができます。
